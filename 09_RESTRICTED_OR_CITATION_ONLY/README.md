# Restricted or citation-only material

This folder separates user-supplied publisher/IEEE copies and citation-only records from the open/public/reference material elsewhere in the archive.

- `user_supplied_restricted/`: copies uploaded by the user for private research. Do not redistribute unless the license permits it.
- `citation_only/`: bibliographic records for important sources whose PDF bytes were not available in this runtime or whose redistribution status is unclear.

The master bibliography in `00_START_HERE/bibliography.csv` is the authoritative status table.
