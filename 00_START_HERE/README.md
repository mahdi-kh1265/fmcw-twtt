This directory contains the navigation and synthesis layer of the corpus.

- `MASTER_INDEX.pdf` - best first document.
- `recommended_reading_order.pdf` - shortest reading path.
- `FMCW_TWTT_Annotated_Source_Atlas.pdf` - exhaustive 84-source map.
- `FMCW_TWTT_Literature_and_Prior_Art_Review.pdf` - technical prior-art synthesis.
- `AWR2944_FMCW_TWTT_MATLAB_Simulation_Blueprint.pdf` - implementation plan for MATLAB V0/V1 and later stages.
- `bibliography.csv` - machine-readable bibliography/status table.
- `CITATION_ONLY_WISHLIST.csv` - the 12 remaining P0/P1 sources without PDF bytes in this build.
- `FULL_FILE_MANIFEST.csv` / `SOURCE_FILE_MANIFEST.csv` - file inventory and hashes.

The mathematical handbook intentionally lives alone in `08_EQUATION_HANDBOOK/` so there is one canonical equation reference.
